# elowe.co photo site

Plain static site: no build step.

- Put photos in `photos/` using the filenames listed in `photos.json`
  (or add new entries to that file). Missing photos show a placeholder tile.
- `IMG_3001.jpg` is the hero image and `IMG_2843.jpg` is the About image.
- Cloudflare Pages settings: framework preset **None**, build command empty,
  output directory `/`.
